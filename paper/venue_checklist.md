## 2. Pre-Submission Verification Checklist

### 2.1 Anonymization & Double-Blind Policy
- [x] Author names, institutions, and acknowledgments omitted or masked in anonymous submission copy.
- [x] Repository links point to an anonymized mirror (e.g., anonymous GitHub or OpenReview zip upload) rather than personal handles.
- [x] Git commits and commit metadata in submission bundles do not contain private author emails.

### 2.2 Results Integrity & Claim Bounding
- [x] Abstract and conclusions match the primary confirmatory result: Primary hypothesis $H_1$ is explicitly reported as **UNSUPPORTED** ($p = 1.000$) due to ceiling/flat responses in simple tasks.
- [x] Prospective validation reports both wins and losses without cherry-picking (Docstring: PromptPrism $0.7658$ vs Random $0.7732$; Sentiment: PromptPrism $0.7761$ vs Random $0.7624$).
- [x] Claims regarding "first" or "optimal" are strictly bounded to two-level fractional factorials for modular prompt component screening.
- [x] Practical neutrality claims require TOST equivalence bounds ($[-\delta, +\delta]$); nonsignificant $p \ge 0.05$ is labeled inconclusive.

### 2.3 Computational Reproducibility
- [x] Single-command offline verification passes cleanly: `python research/reproduce.py` (executes in $\approx 6$ seconds).
- [x] Zero paid API calls are required during reproduction; all fixtures, manifests, and cached evaluations are committed.
- [x] Cryptographic SHA-256 digests and file sizes cataloged in `research/artifact_manifest.json`.
- [x] Frozen environment lockfile committed (`research/environment.lock`).

### 2.4 Ethics, Data & Model Disclosures
- [x] Dataset licenses documented in `research/data/LICENSES.md` (MIT, Apache 2.0, CC-BY-4.0).
- [x] Benchmark items inspected for Personally Identifiable Information (PII) or offensive content; none detected.
- [x] Model terms of use verified for research benchmarking and derivative score publishing (Qwen 2.5 open weights).
- [x] Conflict of Interest (COI) statement disclosed in `research/protocol/coi_statement.md`: Authors evaluate their own software; mitigated via preregistered protocol, frozen hashes, and independent statistical review.

### 2.5 Human Evaluation Audit
- [x] Rater compensation, recruitment, and qualification reported in `research/protocol/human_evaluation.md`.
- [x] Double-blind evaluation: Human annotators evaluated de-identified outputs without knowing model or treatment labels.
- [x] Agreement metrics reported: Human-human Spearman $\rho = 0.898$; Judge-human Spearman $\rho = 0.975$, systematic bias $+0.045$.
