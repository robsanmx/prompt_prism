# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The PromptPrism team takes the security of our library and its users seriously. If you discover a security vulnerability in PromptPrism, please report it responsibly by following these steps:

1. **Do NOT disclose the issue publicly** (e.g. through GitHub public issues or discussions).
2. Email details of the vulnerability to [robsanmx@gmail.com](mailto:robsanmx@gmail.com).
3. Include the following details in your report:
   - Type of issue (e.g. injection, denial of service, dependency vulnerability).
   - Component / module affected.
   - Step-by-step instructions or minimal code snippet to reproduce the vulnerability.
   - Any potential remediation steps you might suggest.

## Response Process

- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide an assessment of the issue and an estimated timeline for a patch.
- Once a fix is verified, we will release a security update and give credit to the reporter (if desired).
